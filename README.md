# Talks

Slide decks by Eric Van Dusen, College of Computing, Data Science, and Society, UC Berkeley.

Decks are built with Quarto (reveal.js) using the shared theme in `slide-kit/`. Rendered slides are published with GitHub Pages from the `docs/` folder.

## Adding a new talk

1. Create a folder named `YYYY-MM-venue/` with the deck as `index.qmd`.
2. Render with `quarto render` from the repo root.
3. Commit and push with GitHub Desktop, then add a row to the table above.
